# Australia's Agricultural Landscape

An interactive data visualisation by Tan Siew Quin, built with Vega, Vega-Lite and Vega-Embed.

Website: https://siewqq.github.io/FIT3179-A2/

## Project files

- `index.html`: the visualisation page, including authorship, data sources and AI declaration.
- `style.css`: page layout and styling.
- `vega_lite_vis.js`: chart embedding and interactive behaviour.
- `js/`: readable Vega and Vega-Lite JSON chart specifications.
- `data/`: the data files loaded by the charts.

## Publishing

GitHub Pages should publish from the `main` branch and the repository root (`/`).
The website URL above is the visualisation submission URL once deployment succeeds.

The original workbooks and large source archives in `Datasets/` are not required to run the website.
